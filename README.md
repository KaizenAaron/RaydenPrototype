# RaydenPrototype

Mock up for Rayden site update. The entire site lives in `index.html` (all assets are embedded), hosted for free on GitHub Pages.

## Going live (one-time setup)

1. Merge this branch into `main`.
2. Make sure the repository is **public** (GitHub Pages is free for public repos): Settings → General → Danger Zone → Change visibility.
3. Go to **Settings → Pages** and set **Source** to **GitHub Actions**.

After that, every push to `main` deploys automatically. The site will be live at:

**https://kaizenaaron.github.io/RaydenPrototype/**

## Custom domain (optional, free)

Add your domain under Settings → Pages → Custom domain and create the DNS records GitHub shows you.
